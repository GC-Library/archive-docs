    Student Newspaper Digitization Project Fields in JSTOR - Metadata Template Explainer#

    Label Type Sample Value Definition Cataloging Forms Repeatable?
    SSID Import field NEW Bulk fill this column to add new items. N/A N
    Filename Import field ofc_001.pdf Uses the collection prefix with numerical count; consult digitization log files. N/A N
    Periodicals Container List field Off-Center Associates a single issue with the full publication page or "container" in JSTOR. Uses Graduate Center Periodicals local container list; bulk spreadsheet requires field code; obtain from container export file. Brief, Full
    Title Text field Enter the publication name and date in this field using the format: Title, Day Month Year Brief, Full
    Volume Number field Enter the volume of a publication. Brief, Full
    Issue Number Text field Enter the issue number of a publication.
    Date Text field Enter date information as it appears on the issue, as text.
    Creator Linked authority field This should be the organization responsible for publishing the issue. Links to LCNAF.
    Publisher Text area The entity responsible for making the resource available.
    Publisher Location Text field The location of the publisher for the periodical. Default value is New York, N.Y. Brief, Full
    Contributor Text field An entity responsible for making contributinos to the content of the resource. Brief, Full
    Related Text field Indicate precursor or successor publication name here using the string "Preceded by xxx" or "Succeeded by xxx" Brief, full
    Description Text area Include any highlights found in the issue, if relevant. Otherwise leave blank. Brief, Full
    Subject Linked authority field The topic of the content of the resource. Linked to LCSH. Brief, Full
    Spatial Coverage Linked authority field Spacial characteristics of the resource. Brief, full
    Type Text field text The nature or genre of the content of the resource; use DCMI terms. Default value is text. Brief, full
    Format Text field pdf/application The file format, physical medium, or dimensions of the resource; use DCMI terms. Default value is pdf/application. Brief, full
    Extent Text field 12 pages Enter the number of pages Brief, Full
    Measurements Text field 3.75 in x 14.5 in. (9.5 cm x 37 cm) Enter the physical dimensions using inches with centimeters in parenthesis. Brief, Full
    Language Linked authority field English A language of the resource; linked to ... Brief, Full
    Local Identifier Text field ofc_001 Enter collection code for publication and numeric sequence for issue PDF Brief, Full
    Resource type List field Newspapers Linked to JSTOR Resource Type list. Brief, Full
    Source Text field Archival collection name, with identifier in parenthesis. Use HTML tags to embed link to finding aid in ASpace. Default value set for each project. Full N
    Repository Text field Name of holding institution/repository with link to info page. Full N
    Rights List field The copyright status of the digital object. Linked to Rights Statement List; use additional info field for item-specific notes Brief, Full N
    Additional Rights/License Information Text area Any additional rights/license information, such as contact information for uses beyond those permitted in the license or intellectual property statement. Brief, Full N
